# 2026-09-15

## Senior-dev code quality audit of Portfolio (src-v2)

Read-only assessment requested ("evaluate this project"). No code changed. Findings verified by running real commands.

### Critical: config/architecture mismatch
- `tsconfig.json` line 19: `"include": ["src"]` — does NOT cover `src-v2/`.
- `index.html` line 21 loads `/src-v2/main.tsx`.
- Consequence: the entire live app (1,609 LOC / 34 files) is completely untype-checked. `tsc -b` exits 0 as a false green because it only sees the legacy `src/` tree.
- Two parallel apps coexist: `src/` (v1, 40 files, ~919 LOC components, includes vite-env.d.ts) vs `src-v2/` (34 files, 1,609 LOC, no vite-env.d.ts).

### Build status (measured)
- `npx tsc -b` → exit 0 (misleading, see above).
- `npm run build` → FAILS. `tsc -b` passes; `vite build` dies in `prepareOutDir` → `emptyDir` → safe-delete/trash shim `ETIMEDOUT` (genie-trash win32-x64.exe). Environment/sandbox artifact, NOT user code — "475 modules transformed" succeeded first.
- `dist/` is stale (index.html Sep 10).

### Dead code found (grep-verified, zero importers)
- Components in src-v2: BeforeAfter, Estimator, FloatingCTA, Marquee, ProjectCard, Gallery — all orphaned. Gallery still references `text-fog` and `border-acid` tokens that do NOT exist in index.css @theme (would render broken if wired up).
- Data: `relatedProjects()` in projects.ts:56 has zero callers. `projectTypes`, `projectIndustries`, `projectSkills` exported, unused.
- `CaseStudy.details: string[]` is populated for all 4 projects but never rendered by CaseStudy.tsx (which renders context/problem instead).

### Bugs
- `Hero.tsx:52` hardcodes `href="#/case-study/nairaflow"` instead of `<Link>`. Couples the hero CTA to one project slug; bypasses router. Should derive from `projects[0]`.
- No `vite-env.d.ts` in src-v2.

### Tooling gaps
- No ESLint, no Prettier, no test runner, no CI.
- `.verdentc.json` deploys via `npm ci && npm run build` → a deploy today ships a broken/stale build.
- Git: only 1 commit ("Initial commit"); EVERYTHING untracked (src-v2/, package.json, etc.). No .gitignore. High data-loss risk.
- `tailwindcss` / `vite` / `typescript` sit in `dependencies` (should be devDependencies for a static site).

### Genuine strengths (noted so future work preserves them)
- `Reveal.tsx` + `Magnetic.tsx` are high quality; `useReducedMotion()` respected in every animated component.
- Clean data-driven separation: `data/site.ts` + `data/projects.ts`.
- `BookingCalendar` uses deterministic `isSlotBooked()` pseudo-availability — smart backend-less approach.
- Tailwind v4 `@theme` tokens; strong a11y (aria-label/pressed/expanded, semantic article/figure/blockquote).
- SVG-only assets, ~227KB total.
