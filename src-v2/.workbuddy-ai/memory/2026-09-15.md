### Correction to the audit — issue #6 was WRONG
The "6 orphan components" (BeforeAfter, Estimator, FloatingCTA, Gallery, Marquee,
ProjectCard) were **never in src-v2/**. They existed only in the v1 tree. The original
grep matched v1 *filenames* against v2 *content* — a false positive. Removing v1
resolved it with zero v2 code lost. **Lesson: verify file existence, not just name matches.**

  unused `EASE` const in Work.tsx. Both fixed. This is the proof the old green was fake.

### Bundle note (NOT fixed — deferred, low priority)
JS is 449 KB raw / 140 KB gzipped. Driver is framer-motion@13 pulling the whole
`motion-dom` engine. App uses only `motion.*`, `useMotionValue`, `useSpring`,
`useReducedMotion`, `AnimatePresence`. Could drop substantially via `LazyMotion` +
`domAnimation` or the `framer-motion/dom/mini` entry. Also consider route-level
`React.lazy` for CaseStudy. Not a correctness issue — leave unless perf matters.

### Environment gotcha (recurring)
`vite build` can fail with `[safe-delete] spawnSync genie-trash win32-x64.exe ETIMEDOUT`
in `prepareOutDir` → `emptyDir`. This is the sandbox trash shim, NOT project code.
Clears once `dist/` is emptied. Do not chase it as a bug.
Separately: `vite preview` returns 502 for assets through the sandbox HTTP proxy even
when files are correct on disk — verify built output by reading `dist/` directly.
