### Icons — new `components/Icon.tsx`
- Six glyphs as inline single paths. **No icon package added**: the app needs six
  glyphs, and brand marks are not in the generic sets (lucide et al).
- Paths fetched verbatim from simple-icons (24×24) and bootstrap-icons (16×16)
  rather than written from memory — a mistyped path renders a broken glyph, and
  long path data is not something to reproduce by hand. **viewBox is stored per
  icon** because the sources differ (16 vs 24).
- Exports an `IconName` union; `data/site.ts` does
  `import type { IconName }` to type the new `icon` field on each social. A typo
  now fails `tsc` instead of silently rendering an empty box.
- `aria-hidden="true"` — every usage sits beside a visible text label.
- Applied to Contact (email button + social links) and Footer (both places, per
  request). Removed the now-redundant "↗" from Contact links.
- Email button `px-9` → `px-8` to offset the added icon, keeping its width ~the
  same as before (it was already close to the edge at 375px).
